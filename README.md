# 贪吃蛇游戏 (Snake Game)

一个使用React、TypeScript和Vite构建的经典贪吃蛇游戏，支持PWA功能。

## 功能特性

- 🎮 使用方向键或WASD控制蛇的移动
- 🎯 具有分数系统和游戏难度调整
- 🌙 支持明暗主题切换
- 🌐 支持中英文双语切换
- 📱 响应式设计，适配不同屏幕尺寸
- 📲 PWA支持，可以安装到设备主屏幕并离线运行

## 技术栈

- React 19
- TypeScript
- Vite
- CSS

## 开发和构建

### 安装依赖

```bash
pnpm install
```

### 开发模式

```bash
pnpm dev
```

### 构建生产版本

```bash
pnpm build
```

### 预览生产版本

```bash
pnpm preview
```

## 游戏控制

- ↑/W：向上移动
- ↓/S：向下移动
- ←/A：向左移动
- →/D：向右移动
- 空格键：开始/暂停游戏
- 重置按钮：重新开始游戏
- 速度滑块：调整游戏难度

## 国际化

使用顶部的语言选择器可以在中文和英文之间切换。

## 主题切换

支持自动检测系统主题，并可以手动切换明暗主题。

## PWA支持

游戏支持渐进式Web应用功能，可以：
- 安装到设备主屏幕
- 离线运行
- 全屏模式运行
